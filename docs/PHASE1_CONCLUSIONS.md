## 1. 核心結論（最重要）

第一階段的唯一阻塞「已還原股價」已**完全解決**，且是**免費解法**。

### 關鍵資料集

`TaiwanStockDividendResult`（FinMind，免 token）提供：

| 欄位 | 用途 |
|---|---|
| `reference_price` | 官方除權息參考價（已含現金股利、股票股利、現金增資等所有調整） |
| `before_price` | 除權息前一交易日收盤價 |
| `date` | 除權息日 |
| `stock_or_cache_dividend` | 權息類型（`息`／`權`／`權息`） |

### 還原股價公式

```text
factor = reference_price / before_price
```

將**除權息日（含）之前**的所有歷史 OHLC 乘上 `factor`，即可得到精確的還原後股價。

配合來源：
- `TaiwanStockPrice`：未還原 OHLC（日線主力來源，11.7 年、免 token）
- `TaiwanStockDividendResult`：官方參考價（用於計算調整因子，免 token）

## 2. 驗證結果

### 2.1 `before_price` 一致性

10 檔、151 筆除權息事件，比對 `before_price` vs `TaiwanStockPrice` 前一交易日收盤價：

- **一致率：151 / 151（100%）**
- 完全吻合，不需額外 Join Price 取前收

### 2.2 精度驗證（官方因子 vs 自算公式）

判準：套用因子後，除權息日的跳空應與一般交易日漲跌分布一致（差異越接近 0 越準）。

| 代號 | 筆數 | 官方因子偏差（`ref/before`） | 自算公式偏差（`(前收−現金)/前收`） |
|---|---|---|---|
| 2330 台積電 | 34 | **+0.194%** | +0.194% |
| 2317 鴻海 | 12 | **+0.373%** | −0.803% |
| 2454 聯發科 | 15 | **−0.718%** | −1.319% |
| 2881 富邦金 | 17 | **−0.244%** | −1.763% |
| 2376 技嘉 | 11 | **−1.314%** | −1.625% |
| **平均絕對偏差** | | **0.750%** | **0.951%** |

→ **官方 `reference_price` 的精度優於單純用現金股利自算的公式。**

### 2.3 涵蓋率與完整性

- **10 檔、151 筆**除權息事件，全部 HTTP 200、**免 token**
- 期間：2015-06 ～ 2026-09，與 `TaiwanStockPrice`（2015-01-05 起）相容
- 對帳：`DividendResult` 的除權息事件是 `Dividend` 的**超集**（部分股票多出數筆）
- **「僅 Dividend 有、僅 Result 有」檢查**：僅 Dividend 有 = 0，證明不會漏事件

### 2.4 為何不用 Google 搜尋到的公式

常見公式：`factor = (前收 − 每股現金股利) / 前收`

此公式**只對純現金股利（息）有效**。遇到**股票股利（權）或權息混合**時會出錯。

實測錯誤幅度：

| 代號 | 除權息日 | 類型 | 官方 `reference_price` | 自算公式值 | 誤差 |
|---|---|---|---|---|---|
| 2317 鴻海 | 2016-09-02 | 權息 | **75.81** | 83.40 | **+7.59 元** |
| 2317 鴻海 | 2015-09-03 | 權息 | **82.66** | 86.80 | **+4.14 元** |

此外，計算配股率需要**股面額**，而 FinMind 免費資料不含股面額。**官方 `reference_price` 已含全部調整，無需區分權息類型，也無需補足股面額。**

## 4. 其他關鍵發現（Phase 1）

| 項目 | 結論 |
|---|---|
| **財務報表** | FinMind 財報已轉**單季值**，TTM 直接加四季，不需相減。統一使用 `IncomeAfterTaxes`（46 期全覆蓋），捨棄長度不足的 `NetIncome`（20 期）。 |
| **EPS** | 單季值，四季加總與年度 EPS 對照通過驗證（差 < 5%）。 |
| **資產負債表** | `_per` 後綴為分析性百分比欄位，**整組忽略**，避免重複計算。 |
| **欄位對應原則** | **必須用英文 `type`／key 硬編碼映射，不可依 `origin_name` 判斷。**（`origin_name` 中文相同不代表語意相同） |
| **靜默錯誤教訓** | 「端點回 200」不代表「參數有效」；名字相近的 dataset 回空不代表功能不存在；真實波動容易被誤判成公式誤差。 |
| **日線來源** | `TaiwanStockPrice`（免 token、11.7 年、完整 OHLC）是日線主力來源。TPEx 歷史日線因日期參數無效而不採用。 |
| **交易日曆** | `TaiwanStockTradingDate` 免費提供 6,936 個交易日（1999–2026）。 |
